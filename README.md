
# 🛒 ClipKart Sales Performance Dashboard — FY 2027

## 📈 Dashboard Features

- **Revenue Analysis:** Compare revenue across product categories.
- **Product Performance:** Identify leading products by revenue.
- **City-wise Sales:** Compare sales performance across cities.
- **Category Distribution:** Understand each category's contribution to revenue.
- **Price vs. Revenue:** Explore revenue patterns across product prices.
- **KPI Monitoring:** Track key business metrics in one place.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Data Visualization** — KPI cards, bar charts, column charts, tables, and doughnut charts
- **Business Intelligence** — Sales performance reporting and analysis
